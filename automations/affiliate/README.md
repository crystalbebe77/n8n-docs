# アフィリエイト下書き自動生成（n8n）

**これは下書きです。** 実際に動かす前に、下の「自分で設定するところ」を全部埋めてください。

## 何をする仕組みか

毎朝8時に、スプレッドシートの商品リストから「未処理」の行を3件とって、AIが紹介文の下書きを作り、
別シートに保存して、あなたに確認依頼のメールを送ります。

```
毎朝8時
  → 商品リストを読む（Google Sheets）
  → 未処理を3件だけ選ぶ（Code）
  → 紹介文を下書きする（Claude）
  → リンクと広告表記をつける（Code）
  → 下書きシートに保存（Google Sheets）
  → 商品リストを「下書き済」にする（Google Sheets）
  → メール文面を作る（Code）
  → 承認依頼メール（Gmail）
```

**投稿は自動化していません。** 下書きシートを見て、自分で確認してから投稿します。
公開・投稿は人が判断する、という前提で組んであります。

## 必要なもの

- n8n（クラウド版でもセルフホストでも可）
- Google アカウント（スプレッドシートとGmail）
- Anthropic の API キー

## 1. スプレッドシートを用意する

1つのスプレッドシートに、シートを2つ作ります。シート名も列名もこの通りにしてください
（Codeノードが日本語の列名をそのまま参照しています）。

### シート「商品リスト」

1行目に、この見出しを入れます。

| id | 商品名 | カテゴリ | 価格 | メモ | アフィリエイトリンク | ASP | ステータス |
|----|--------|---------|------|------|--------------------|-----|-----------|

- `id` は重複しない値にしてください（P001, P002 など）。行の更新に使います。
- `ステータス` が空欄か「未処理」の行だけが処理されます。
- 処理が終わると「下書き済」に変わり、次回からは選ばれません。

`sheet-template.csv` をインポートすれば、見出しとサンプル行が入ります。

### シート「下書き」

1行目にこの見出しを入れます。中身はワークフローが書き込みます。

| id | 生成日時 | 商品名 | ASP | タイトル案 | 本文 | ハッシュタグ | 投稿用テキスト | 要確認 | ステータス |
|----|---------|--------|-----|-----------|------|------------|--------------|--------|-----------|

## 2. n8n にインポートする

n8n の画面で **Workflows** → **Import from File** → `affiliate-draft-generator.json` を選びます。

## 3. 自分で設定するところ

インポートしただけでは動きません。次の5か所を開いて設定してください。

| ノード | やること |
|--------|---------|
| 商品リストを読む | Google Sheets の認証情報を作る。Document でスプレッドシートを選び、Sheet で「商品リスト」を選ぶ |
| Anthropic Chat Model | Anthropic の認証情報を作る。Model を一覧から選ぶ |
| 下書きシートに保存 | Document を選び、Sheet で「下書き」を選ぶ。Mapping Column Mode を **Map Automatically** にする |
| 商品リストを下書き済みにする | Document を選び、Sheet で「商品リスト」を選ぶ。Column to Match On を `id` にする |
| 承認依頼メール | Gmail の認証情報を作る。宛先が `your-address@example.com` のままなので、自分のアドレスに変える |

JSON の中のスプレッドシートURLは `<ここにスプレッドシートIDを入れる>` という仮の値です。
画面から選び直せば上書きされます。

## 4. 試す

いきなり毎朝動かさず、まず手で試してください。

1. 商品リストに1行だけ入れて、ステータスを「未処理」にする
2. n8n の **Execute workflow** を押す
3. 下書きシートに1行増えたか、メールが届いたかを見る
4. 問題なければ、ワークフローを **Active** にする

## 調整するところ

### 1回に作る件数

「未処理を選ぶ」ノードの先頭。

```js
const MAX_PER_RUN = 3;
```

### 文体

「紹介文を下書きする」ノードの Prompt。いまは次のルールが入っています。

- やわらかいけれど丁寧すぎない
- 過剰な宣伝、感動ストーリー、煽り文句は書かない
- 「絶対」「必ず」「最安」など断定・最上級は使わない
- 商品リストに書いていないことは書かない（サイズ・素材・効果を推測で補わない）
- 書けなかった点は `note` に書く

自分の投稿の見本があれば、Prompt に貼ると文体が寄ります。

### 広告表記

「リンクと広告表記をつける」ノードの先頭。

```js
const AD_LABEL = 'PR / 広告を含みます';
```

ステマ規制（景品表示法の指定告示、2023年10月1日施行）に対応するため、必ず入るようにしてあります。
**ただし、求められる表記の文言や置き場所はASP・SNSごとに違います。** 自分が使うASPの規約を確認して、
必要ならこの文字列を変えてください。ここはこちらで確認できていません。

## 「要確認」列について

下書きシートの `要確認` 列に、そのまま出せない理由が入ります。空欄なら特に問題なしです。

- `アフィリエイトリンクが空欄` … 商品リストのリンクが未入力
- `AIの回答がJSONとして読めなかった` … 本文がそのまま入っているので、手で整える
- `AIからの申し送り: ...` … AIが情報不足だと判断した点

情報が足りないときに勝手に埋めない作りにしてあります。

## 確認できていること / できていないこと

**動かして確認したこと**

- 3つのCodeノードの動作。未処理の絞り込み、件数制限、コードフェンス付きJSONの読み取り、
  JSONで返ってこなかったときの退避、リンク・ハッシュタグ・広告表記の連結、メール文面の組み立て。
  ダミーデータを流して出力を確認済み。
- ノードのtype名とJSONの形。このリポジトリの n8n 公式ワークフロー例と突き合わせ済み。

**確認できていないこと**

- 実際の n8n に読み込ませての動作。この環境に n8n がないため未実行。
- Google Sheets と Gmail ノードの細かい項目名。n8n のバージョンで変わることがあるので、
  インポート後に画面で確認してください（上の表の通り）。
- Anthropic Chat Model で選べるモデルの一覧。n8n のバージョンによって違います。
- ASPごとの広告表記のルール。

**既知の制約**

- AIの出力と商品データは、順番で対応づけています。通常は入力順のまま返りますが、
  もし対応がずれたら、下書きシートの商品名と本文が食い違うので気づけます。
- Google Sheets の「Append or Update」は `id` 列で行を探します。`id` が重複していると別の行を上書きします。
